# Tianyun Ma's Academic Homepage

Source code for [matianyun.github.io](https://matianyun.github.io).

The site is built with [Jekyll](https://jekyllrb.com/) and adapted from the [al-folio](https://github.com/alshedivat/al-folio) academic theme. Its layout and publication presentation are inspired by [Zhongkai Yu's homepage](https://zhongkaiyu.github.io/).

## Local development

```bash
bundle install
bundle exec jekyll serve
```

The production site is built and deployed through GitHub Actions after changes are pushed to `main`.
